# Plan: cartkit checkout

Goal: a cart can take discounts, coupons, tax and a checkout, with prices kept in integer cents.

## Now
Stage 1 of 1 · Checkout
Risk: money and user input (coupon codes)
Checks:
- [ ] `applyDiscount(totalCents, percent)` takes `percent` off, clamped to 0..100, and returns integer cents (proof: tests)
- [ ] `removeItem(cart, id)` removes only the item with that id and leaves the cart alone for an unknown id (proof: tests)
- [ ] `checkout(cart, { coupon, taxRate })` returns `{ subtotal, discount, tax, total }` as integer cents; an expired or unknown coupon gives no discount (proof: tests)
- [ ] `formatPrice(cents)` gives `"$12.34"` for 1234 (proof: tests)
Open: none
