## Findings for the PM
- **The model disabled the probe hook.** In the first `Stop` "continue" run, after 6 continues the model ran `run_command` unprompted in `-p` auto mode (`find`, `ps aux`, …) and wrote `log` into `$HOME/PROBE_MODE`, so the 7th Stop got `{}` and the run ended early ([verify/check3-stop-tampered.txt](verify/check3-stop-tampered.txt)). A re-run with writes denied reached the cap. This sharpens the note's open concern: stage 2's hook must not keep mode or state anywhere the model can write with an allowed tool, and the guard must cover shell writes to it.
- **The note and the plan disagree on `CLAUDE.md`.** The note's "What this means for stage 2" says to write `@[CLAUDE.md](CLAUDE.md)` into `AGENTS.md`; the plan's later (unattended) decision settles on pointing at `CLAUDE.md` in the package's rules and not writing the project's `AGENTS.md`. The plan is the later word; the note's bullet is stale.
- Small differences, not disagreements: the builders' context run had 3 invocations, mine 4 (prompt-dependent); the Stop cap of 10 matches `hooks-stop/01`.
- Verifier slip: one `agy --version` call ran with `HOME=/x` and without `AGY_CLI_DISABLE_AUTO_UPDATE=1`, before any throwaway home existed; `/x` was not created and the binary hash was unchanged afterwards.
