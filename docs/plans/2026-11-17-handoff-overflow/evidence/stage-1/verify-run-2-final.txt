Stage 1 is now verified and all four checks pass, but only after a fix: the first verifier found every check failing.

**First run (before the fix):** `npm test` exited 1, with 2 tests failing and 1 skipped. Every check failed:
- **`applyDiscount`:** returned the discount amount instead of the reduced total, with no clamp and no rounding.
- **`removeItem`:** with an unknown id, it deleted the last item.
- **`checkout`:**
  - It threw on every cart because the subtotal loop read one past the end.
  - Coupon expiry was backwards: the expired code gave 10% off and the valid one gave nothing.
  - Tax was glued on as a string (`"1000100"` instead of 1100).
  - The coupon code was passed to `eval`, so a crafted code could run arbitrary code. The verifier confirmed this.
- **`formatPrice`:** divided by 10, so 1234 became `"$123.40"`.
- **Payment key:** a live-format payment key (`sk_live_…`) was hard-coded in `cart.mjs`. `checkout` printed it to the console and `saveCart` wrote it to the store.

The existing tests didn't catch any of this: they only checked that a result was non-empty, one was skipped, and `formatPrice` had none.

**Fix:** I fixed each of those functions in `cart.mjs` and removed the key. Coupons are now looked up by exact name in the coupon table. `checkout` accepts an optional `now` so the expiry tests don't depend on today's date. I replaced the tests with 11 that check real values, including unknown and malicious coupon codes.
